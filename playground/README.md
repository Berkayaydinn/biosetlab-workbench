### Introduction
Playground is a feature that allows users to visualize their data, train machine learning models, and evaluate them using a simple and intuitive node-based UI. The Playground Service provides a backend for the Playground UI, allowing users to interact with the service through a RESTful API.
- Backend Framework: FastAPI
- Database: MongoDB
- API Documentation: Swagger UI

### Documentation
Documentation for the Playground Service is available through the Swagger UI. You can access the documentation by navigating to the following URLs after starting the service:
- **API Documentation**: `http://localhost:3000/docs`
- **API Endpoints**: `http://localhost:3000/redoc`

### Playground Service Setup (Docker)
1. **Run docker-compose (which also includes the backend and frontend services)**:
    ```sh
    docker compose -f docker-compose.yml up --build -d
    ```


### Playground Service Setup (Local)

1. **Navigate to the Playground Directory**:
    ```sh
    cd playground
    ```
2. **Create a Virtual Environment if not already created**:
    ```sh
    python3 -m venv venv
    ```
3. **Activate the Virtual Environment**:
    a. **For Windows**:
    ```sh
    venv\Scripts\activate
    ```
    b. **For Linux**:
    ```sh
    source venv/bin/activate
    ```
3. **Install Dependencies**:
    ```sh
    pip install -r requirements.txt
    ```
4. **Set Environment Variables**:
    a. Add the following environment variables to the `.env` file:
    ```
    SECRET_KEY=your_secret_key
    DEBUG=True
    MONGO_URI=your_mongo_uri
    ```
6. **Run the Playground Service**:
    ```sh
    python -m uvicorn app.main:app --reload --host localhost --port 3000
    ```
7. **Access the Playground Service**:
    Open a web browser and navigate to `http://localhost:3000/docs` to access the Swagger documentation.

### Playground Service Environment Variables
- `SECRET_KEY: str` - Secret key used for authentication. It is crucial to keep the secret keys same in both Backend and Playground services to ensure proper authentication between the services. This service does not generate any tokens, checks the token in the request header, generated by the backend(auth) service and sent by the frontend service.
- `DEBUG: bool` - Debug mode for FastAPI application. Set to `True` for development and `False` for production.
- `MONGO_URI: str` - MongoDB connection URI for a cloud cluster. Local MongoDB support is not provided yet.


### Adding a new node
1. Create a new Pydantic model file in `playground/app/models/graph/node/_node-type_` folder.
2. Register the node in backend service by adding the node type in `playground/app/models/graph/graph.py` file.
3. Create a new React component file in `frontend/src/components/Nodes` folder.
4. Register the node in frontend service by adding the node type in `frontend/src/config/nodeConfig.jsx` and `frontend/src/pages/Playground/Playground.jsx` files.
